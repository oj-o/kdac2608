# GitHub Pages 모바일 인터랙티브 미디어아트

## 목적

지체장애 관람자가 별도의 조작 장치를 사용하지 않아도
카메라와 마이크를 통해 자신의 감상 반응을 작품의 변화로 표현할 수 있도록 하는 프로토타입.

## GitHub Pages에서 실행

1. GitHub에 새 repository 생성
2. `index.html`을 repository 최상위에 업로드
3. `Settings` → `Pages`
4. `Deploy from a branch`
5. `main` / `/ (root)` 선택
6. 배포된 `https://사용자명.github.io/저장소명/` 주소를 모바일 Chrome에서 열기
7. 최초 1회 카메라와 마이크 권한 허용

GitHub Pages의 github.io 사이트는 HTTPS로 제공되므로 카메라/마이크 웹 API 사용에 필요한 보안 컨텍스트를 만족한다.

## 인터랙션

### 카메라
- 실제 카메라 영상 사용
- 화면 프레임 변화량으로 몸짓/움직임의 크기를 계산
- 얼굴 위치로 작품 중심 이동
- MediaPipe Face Landmarker로 표정 변화 분석
- 미소 / 입 벌림 / 눈썹 변화 등을 작품 상태에 반영

### 마이크
- 실제 마이크 사용
- 음량 분석
- 피치 분석
- 한국어 음성인식 지원 브라우저에서 음성 내용 분석

### 작품 변화

```text
몸짓 증가
→ 입자 수 증가
→ 속도 증가

미소
→ 밝은 색
→ 확장되는 그래픽

입 벌림/눈썹 변화
→ 에너지 증가

고개 이동
→ 작품 중심 이동

큰 목소리
→ 그래픽 크기 증가

높은 피치
→ 색조/사운드 변화

"편안해"
→ 편안한 분위기

"무서워"
→ 긴장된 움직임

"재밌어"
→ 흥미로운 움직임
```

## 접근성 원칙

- 작품의 핵심 조작으로 버튼을 사용하지 않는다.
- 사용자의 손 정밀 동작을 요구하지 않는다.
- 움직임이 작은 경우에도 값이 지속적으로 smoothing되어 반영된다.
- 카메라가 작동하지 않으면 마이크 기반 경험을 유지한다.
- 마이크가 작동하지 않으면 카메라 기반 경험을 유지한다.
- 얼굴/감정을 의료적 또는 심리적 진단으로 사용하지 않는다.
- 입력은 감상 표현을 위한 인터랙션 재료로만 사용한다.

## 중요한 기술 조건

카메라와 마이크는 웹 브라우저의 `getUserMedia()`를 사용한다.
이 기능은 사용자 권한이 반드시 필요하다.

완전한 오프라인 `file://` 실행과 실제 카메라/마이크를 동시에 보장하는 방식이 아니라,
**GitHub Pages의 HTTPS 웹사이트에서 실행하는 전시용 구조**다.

표정 분석 모델은 MediaPipe Tasks Vision CDN과 Google Storage의 모델 파일을 불러오기 때문에 최초 접속 시 인터넷 연결이 필요하다.

## 파일

```text
index.html
README.md
```

별도의 Node.js, Python, localhost 서버는 필요하지 않다.
